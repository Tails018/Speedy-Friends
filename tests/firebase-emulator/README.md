# Pruebas aisladas de reglas de Realtime Database

`database.candidate.rules.json` deriva de la copia facilitada por la propietaria en `../../rules/realtime-owner-reference.json`, cuya procedencia y versión publicada no están verificadas. Conserva todas sus rutas, pero solo endurece perfiles, retira la autorización de noticias basada en `users/$uid/role` y añade el índice de users/ownerUid. El resto mantiene riesgos conocidos. **No desplegar.** Ver `../../docs/AUDITORIA-FIREBASE-V53.md` para compatibilidad y migración.

Requisitos: Node 22+, Java 21 y acceso para dependencias y emulador. Desde este directorio ejecutar `npm ci` y `npm test`. El comando usa exclusivamente el proyecto ficticio `demo-speedy-friends`, reglas explícitas y emulador local `127.0.0.1:19000`; los tests rechazan otra dirección. No se ejecuta despliegue ni se modifican datos reales.

En Windows, si la instalación normal falla con EPERM, se ha ejecutado en una copia temporal con `npm ci --install-strategy=shallow --ignore-scripts`, JRE Temurin portátil y `XDG_CONFIG_HOME` en una carpeta escribible. La resolución previa del lock informó 21 vulnerabilidades transitivas (16 moderadas y 5 altas); deben revisarse. La suite pasó 17 pruebas en el emulador oficial (cuatro reproducen ataques en la copia original y trece comprueban el candidato) el 31 de octubre de 2026. Esta cobertura limitada no acredita seguridad ni compatibilidad de la plataforma completa.

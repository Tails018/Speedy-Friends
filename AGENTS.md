# Instrucciones para Speedy Friends

- Trabajar sobre la rama de desarrollo acordada; no sobrescribir cambios ajenos ni desplegar Firebase sin autorización explícita.
- Las reglas y controles del navegador no sustituyen autorización en Firebase ni lógica económica confiable. Nunca confiar precios o saldos al cliente.
- Mantener compatibilidad con HTML, CSS y JavaScript existentes; evitar migraciones de framework sin necesidad.
- Conservar las pruebas existentes y añadir pruebas relevantes para cambios funcionales. Distinguir mocks de emuladores oficiales y dispositivos físicos.
- Evitar exponer datos privados, credenciales o tokens; proteger movimiento reducido y accesibilidad al modificar interfaces.
- Documentar migraciones, riesgos y límites comprobados; no presentar reglas locales como reglas de producción sin verificarlas.
